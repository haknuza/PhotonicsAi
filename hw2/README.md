belong here so Task 2 can use the same executor.

- `task2/` is reserved for the DMD simulator and focusing tool.

The repository did not contain Homework 2 run (a)/(b) artifacts or DMD/focusing-tool source, so
those two folders are intentionally placeholders for now.
